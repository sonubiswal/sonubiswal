## 🚀 Featured Projects

### 🌦️ Weather Forecasting

> **A desktop weather app that queries four independent forecast models in parallel, reports the median with a confidence spread, and grades its own accuracy against observed conditions.**

It doesn't just show a forecast — it **scores itself**, benchmarking against persistence and ECMWF IFS baselines so you can see exactly when the ensemble is worth trusting.

**Stack:** `Python` · `PySide6` · `Open-Meteo` · `Folium`

[![Repo](https://img.shields.io/badge/Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/sonubiswal/Weather-Forecasting)

---

### ⚡ EV Charging Finder

> **Find the nearest EV charging station in India, with a real driving route drawn on an interactive map.**

Ships with a modern 3D landing page, a live demo, and a Python backend that generates standalone HTML maps — geocoding, routing, and rendering end to end.

**Stack:** `Python` · `Folium` · `geopy` · `Nominatim` · `OSRM` · `Leaflet`

[![Repo](https://img.shields.io/badge/Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/sonubiswal/EV-Charging-Finder)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-22c55e?style=for-the-badge&logo=githubpages&logoColor=white)](https://sonubiswal.github.io/EV-Charging-Finder/)
